# Грузовые аукционы — SPA

Single-page application для грузовых аукционов. Разработано с использованием React + TypeScript + Vite.

## Стек технологий

- **React 19** + **TypeScript 6**
- **Vite 8** — сборка
- **TanStack Router** — роутинг
- **TanStack Query** — управление данными
- **React Hook Form** + **Zod** — формы и валидация
- **Zustand** — UI-состояние (тосты)
- **MSW v2** — мок-сервер для разработки
- **Feature-Sliced Design** — архитектура

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу http://localhost:5173.

## Сборка

```bash
npm run build
```

## Тесты

```bash
npx vitest run
```

## Структура проекта

```
src/
├── app/              # Инициализация, провайдеры, роутер
├── pages/            # Страницы (auctions-list, auction-detail, auction-bets)
├── features/         # Фичи (place-bet)
├── entities/         # Сущности (auction)
├── shared/           # Переиспользуемые модули
│   ├── api/          # HTTP-клиент, типы, MSW моки
│   ├── lib/          # Утилиты
│   ├── store/        # Zustand store
│   └── ui/           # Общие UI-компоненты
```

## Сценарии проверки

1. **Список аукционов**: открыть `/` — увидеть 12 аукционов с пагинацией
2. **Фильтры**: развернуть фильтры, выбрать тип "Down", город "Москва"
3. **Детальная страница**: кликнуть на карточку → страница с полной информацией
4. **Ставки**: нажать "Смотреть ставки" → список ставок
5. **Разместить ставку**: нажать "Сделать ставку" → форма → ввести цену → отправить
6. **Адаптив**: изменить размер окна — интерфейс адаптируется
